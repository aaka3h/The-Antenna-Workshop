# 📡 The Antenna Workshop

> A DIY antenna encyclopedia with an AI-powered assistant — build guides for 12 antenna types covering ham radio, WiFi, SDR, and satellite reception.

🌐 **Live Site:** [aaka3h.github.io/The-Antenna-Workshop](https://aaka3h.github.io/The-Antenna-Workshop)

---

## What's Inside

12 complete DIY antenna build guides — each with materials list, step-by-step instructions, dimensions, SVG diagrams, and pro tips:

| Antenna | Difficulty | Best For |
|---|---|---|
| Half-Wave Dipole | Easy | FM radio, HF/VHF ham radio |
| Ground Plane Vertical | Easy | ADS-B, weather satellites, VHF |
| Cantenna (Tin Can) | Easy | Long-range WiFi 2.4 GHz |
| Yagi-Uda | Medium | TV reception, amateur radio, directional WiFi |
| J-Pole | Medium | 2m/70cm amateur radio |
| Magnetic Loop | Medium | Indoor HF, apartment operation |
| Parabolic Dish | Medium | Extreme range WiFi, microwave links |
| Bi-Quad | Medium | Directional WiFi, dish feedhorn |
| Beverage Wire | Medium | LF/MF/HF DX receiving |
| Cubical Quad | Hard | HF DX, high gain directional |
| Helical | Hard | Satellite reception, circular polarisation |
| Discone | Hard | Wideband SDR scanner, 25 MHz – 3 GHz |

## AI Antenna Expert

The site includes a built-in AI chat assistant powered by **Google Gemini**:

- Ask any antenna question and get expert DIY answers
- Calculates element lengths and dimensions for any frequency
- Generates visual SVG diagrams inline
- Suggests materials and tools
- Completely free — bring your own Gemini API key

**Get a free API key:** [aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey)
*(Free tier: 1,500 requests/day — more than enough)*

## How to Use

1. Open the [live site](https://aaka3h.github.io/The-Antenna-Workshop)
2. Browse antennas in the left sidebar
3. Click **📡 Ask AI** in the bottom-right corner
4. Enter your free Gemini API key on first use (saved in your browser)
5. Ask anything — *"How do I build a Yagi for 2m?"*, *"What antenna for ADS-B?"*, etc.

---

## Run Locally

No build step needed — it's a single HTML file:

```bash
git clone https://github.com/aaka3h/The-Antenna-Workshop.git
cd The-Antenna-Workshop
# Open index.html in any browser
start index.html
```
